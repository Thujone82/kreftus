Sudoku v1.4

Sudoku is a console puzzle game written in Go with tcell. Fill the 9×9 grid so every row, column, and 3×3 box contains the digits 1–9. Given clues are locked; a correct entry locks the same way so it cannot be changed by accident. Wrong digits stay in the cell with a red fill so you can correct them. Puzzles come from the public-domain Sudoku Exchange Puzzle Bank (Grant McLean): 2500 Easy, 2000 Medium, 1000 Hard, and 250 Diabolical. Solved IDs are never offered again.

Controls

Menu: ↑↓ select, ←→ change difficulty, Enter to Continue or start New Game. In game: Arrows or WASD to move (wraps at the edges), Tab toggles ✒️ pen / ✏️ pencil, hold Shift for momentary pencil marks (number row or keypad; arrows and WASD still move), 1–9 to enter a digit or add/toggle a pencil mark (completed numbers are ignored), 0/Backspace/Delete to clear, Space to pause. Esc returns to the menu (the game is saved). Ctrl+C exits and keeps Continue for next launch.

Features

  • Start menu: difficulty header, then Continue (when that difficulty has a save), New Game, Quit; Stats below (Remaining always; full stats after a win); ←→ changes difficulty
  • UTF-8 box-drawn 9×9 board; each digit 1–9 has its own hue; a digit turns white when all nine of that number are correctly placed; clues and locked-correct cells are bold
  • Accent-colored ▶ ◀ ▼ ▲ around the grid track the selected row and column
  • Centered Active strip under the board lists unfinished numbers in their hues and drops a number once all nine are placed
  • Wrong entries stay visible with a maroon cell; correct lock-in cannot be overwritten or cleared
  • Green grid-border flash (~0.6s) on a correct lock-in; red flash on a mistake
  • 16-color accent wheel: random hue at launch; +1 on menu or board movement and correct lock-in; −8 on a mistake; pencil mode reverses movement and mark rotation
  • Pencil marks: Tab toggles ✒️ / ✏️; hold Shift for momentary pencil (number row or keypad; arrows and WASD still move); New Game starts in pen, Continue restores the saved mode; up to two candidate colors per empty cell on a ▀ glyph; pressing a marked digit toggles it off; a correct lock-in strips that color from the row, column, and box (completing a number strips it everywhere; leftover drops to the bottom half); saved with Continue
  • Pause shows the rainbow SUDOKU banner, difficulty, a fill progress bar, and Pencil Marks / Errors when present; Space resumes, Esc returns to the menu
  • Solved overlay: double-line box with Time and Errors, or Perfect Finish! on a zero-error win; Press Enter returns to the menu
  • Esc during play or pause returns to the menu and keeps that difficulty's continue; Abandon (counts as Failed) only when starting New Game over an existing save at the same difficulty
  • Per-difficulty Perfect, Successes, Error Rate, Failed, fastest time, Average Completion, and remaining puzzle count
  • sudoku.json saves after every move; one continue per difficulty; completions store puzzle id, mistake count, and elapsed time; finishing records Success and wipes that difficulty's Continue immediately so the menu will not offer that game again
  • Auto-requests 80×24 console; Windows UTF-8 (CP65001) and Cascadia Mono when present
