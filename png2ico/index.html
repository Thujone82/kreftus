png2ico v1.1.0 — PNG to ICO

png2ico v1.1.0

png2ico is a Python command-line converter that takes a square PNG (256×256, 512×512, 1024×1024, or 2048×2048) and writes a Windows .ico beside it with the same name. Larger sources are downscaled with LANCZOS to the common Windows icon sizes and packed into one ICO file. Built with Pillow.

Features:

  • Exact input size: Only 256×256, 512×512, 1024×1024, or 2048×2048 PNG is accepted — any other size is an error and no ICO is written.
  • Common Windows sizes: 16×16, 24×24, 32×32, 48×48, 64×64, 128×128, and 256×256 in one ICO. 256×256 is PNG; smaller sizes are 32-bit BMP/DIB so Explorer and .exe icons display correctly.
  • Same-folder output: app.png becomes app.ico next to the source file.
  • Step-by-step feedback: Prints each conversion step and ends with Success or Failed.
  • Help: -h, -help, and --help.

Run python png2ico.py path\to\icon.png from python/png2ico/ after pip install -r requirements.txt.
